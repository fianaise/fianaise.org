# fianaise.org

Redirects every fianaise.org address to the same page on [fianaise.ie](https://fianaise.ie).

GitHub Pages serves `index.html` for the home page and `404.html` for every other path, and both forward to fianaise.ie with the path, query and anchor kept. The site's own source is in [fianaise/fianaise.ie](https://github.com/fianaise/fianaise.ie).

DNS for fianaise.org (Blacknight): four A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153, and a CNAME for `www` pointing to fianaise.github.io.
